## 설비 개요

- 신발 부품을 금형에 고정하고 압력·열로 성형 또는 접착하는 2스테이션 프레스입니다.
- 상부 압착 헤드, 하부 금형, 공압 계통, 발 페달 및 조작 패널로 구성됩니다.
- 실제 작업 온도, 압력, 성형 시간은 제조사 매뉴얼 확인 후 설정합니다.

## ⚠️ 안전 수칙

- [ ] 작업 전 보안경과 내열 장갑을 착용한다.
- [ ] 헐거운 장갑, 소매, 목걸이를 제거한다.
- [ ] 압착부와 금형 사이에 손을 넣지 않는다.
- [ ] 발 페달 주변에 자재와 장애물을 두지 않는다.
- [ ] 금형 교체 전 전원을 차단하고 에어를 완전히 배출한다.
- [ ] 뜨거운 금형과 헤드는 충분히 식힌 뒤 만진다.
- [ ] 안전커버, 양수조작장치, 인터록을 임의로 해제하지 않는다.
- [ ] 압력 누설, 비정상 소음, 탄 냄새가 나면 즉시 정지한다.
- [ ] 정비는 잠금·표지(LOTO) 후 실시한다.

## 일일 점검 체크리스트

- [ ] 전원 케이블, 플러그, 접지 상태를 확인한다.
- [ ] 비상정지 버튼을 눌러 정상 정지되는지 확인한다.
- [ ] 시작 전 비상정지 버튼을 복귀한다.
- [ ] 공압 공급 압력이 작업 기준인지 확인한다. 기준값은 제조사 매뉴얼 확인.
- [ ] 에어호스, 피팅, 실린더에서 누설음이 없는지 확인한다.
- [ ] 에어 필터의 물과 오염물을 배출한다.
- [ ] 압력계 표시와 조절기 상태를 확인한다.
- [ ] 상부 헤드와 하부 금형에 균열, 풀림, 오염이 없는지 확인한다.
- [ ] 금형 고정 볼트와 위치 고정장치를 확인한다.
- [ ] 압착 패드의 마모, 경화, 들뜸을 확인한다.
- [ ] 발 페달이 걸림 없이 복귀하는지 확인한다.
- [ ] 각 스테이션의 상승·하강 동작이 부드러운지 확인한다.
- [ ] 설정 온도와 실제 표시 온도를 확인한다. 허용 편차는 제조사 매뉴얼 확인.
- [ ] 시험품으로 압착 위치와 성형 품질을 확인한다.
- [ ] 작업 후 금형과 압착면의 접착제·이물질을 제거한다.

## 주간·월간 점검

### 주간 점검

- [ ] 에어 필터와 레귤레이터를 청소한다.
- [ ] 실린더 로드에 흠집, 부식, 오일 누유가 없는지 확인한다.
- [ ] 공압 호스의 꺾임, 마모, 균열을 확인한다.
- [ ] 힌지, 링크, 슬라이드부의 풀림과 유격을 확인한다.
- [ ] 제조사 지정 윤활부에 지정 윤활제를 보충한다.
- [ ] 조작 버튼, 표시등, 터치패널 반응을 확인한다.
- [ ] 좌·우 스테이션의 압착 위치와 압력이 동일한지 시험한다.

### 월간 점검

- [ ] 전원을 차단하고 단자대, 배선, 접지선을 점검한다.
- [ ] 전기함 내부의 먼지를 제거한다.
- [ ] 히터, 온도센서, 온도조절기의 이상 유무를 점검한다.
- [ ] 압력계와 온도 표시값의 정확도를 검증한다.
- [ ] 금형 정렬과 평행도를 점검한다.
- [ ] 마모된 압착 패드, 씰, 호스는 교체한다.
- [ ] 안전장치 기능을 점검하고 결과를 기록한다.
- [ ] 소모품 교체 주기는 제조사 매뉴얼 확인 후 관리한다.

## 이상 징후와 조치

| 이상 징후 | 즉시 조치 |
|---|---|
| 헤드가 내려가지 않음 | 비상정지 복귀 상태, 공압 공급, 발 페달, 인터록을 확인한다. 계속되면 정비 담당자에게 알린다. |
| 헤드가 천천히 움직임 | 공압 압력과 누설을 확인한다. 필터 막힘과 실린더 이상을 점검한다. |
| 압착력이 약함 | 압력계와 레귤레이터 설정을 확인한다. 호스 누설과 실린더 씰을 점검한다. |
| 좌우 성형 품질이 다름 | 금형 위치, 패드 마모, 압력·온도 설정을 비교한다. |
| 온도가 오르지 않음 | 설정값, 히터, 센서, 차단기를 점검한다. 전기 정비는 자격자에게 맡긴다. |
| 온도가 과도하게 상승함 | 즉시 작업을 중지한다. 전원을 차단하고 온도제어기·센서를 점검한다. |
| 제품에 눌림 자국·접착제 묻음 발생 | 금형과 패드를 청소한다. 압력, 시간, 온도는 제조사 매뉴얼 기준으로 재설정한다. |
| 공기 누설음이 남 | 설비를 정지하고 호스·피팅·밸브를 점검한다. 손상 부품을 교체한다. |
| 탄 냄새·연기·스파크 발생 | 즉시 비상정지한다. 주전원을 차단하고 재가동하지 말고 전기 담당자에게 알린다. |
